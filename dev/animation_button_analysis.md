# Animation Action Button

`tests/replay_animation_button_base.txt` creates a segment and a point at its midpoint. In Sketchpad 5, selecting the point and choosing Edit > Action Buttons > Animation opens a settings dialog. Accepting its defaults creates a code-62 button labeled `动画点` (Animate Point). The native file is `tests/fixtures/action_animation_original.gsp`.

The button group has seven records: `0x07d0` (28-byte header), `0x07d2` (one target, point 4), `0x07d3` (36-byte animation settings), `0x0906` (24-byte action payload), `0x07d5` (label), `0x07d8` (auxiliary), and `0x07d7` (terminator). The action payload has nested code `0x0906`, length 24, code 12 at offset 8, value 2 at offset 12, and the button's screen anchor at offsets 20–23. `assets/action_animation_group.bin` preserves the native 188-byte group. The settings payload remains opaque so its unrecognized fields survive file edits.

Clicking the native button moved the constrained point from parameter 0.5 to 0.60276 in the saved sample while leaving the button group unchanged. The clicked file is `tests/fixtures/action_animation_clicked.gsp`. The native button did not show a floating Motion Controller in the click capture.

The port decodes this default group as an editable Animation Button. Edit > Action Buttons > Animation creates one for a free point or a point on a segment, circle, or arc. A click starts that point in the existing motion engine without opening the controller. The native and clicked files import with `partial_view=false` and reencode byte-identically. `tests/replay_animation_button.txt` creates an English `Animate Point` button. Sketchpad 5 opened and saved that port-generated file byte-identically (2,240 bytes, 91 records). Clicking it moved the point; the resulting native save is `tests/fixtures/action_animation_port_clicked_by_wine.gsp` and reencodes byte-identically in the port. Desktop captures at `/tmp/sketchpad_animation_button_port_before.png` and `/tmp/sketchpad_animation_button_port_after_one.png` show the port button and the point's motion.

## Direction, speed, and travel

For a point on a segment, changing the native Direction menu altered only byte 7 of the `0x07d3` settings payload: `0x00` forward, `0x10` backward, `0x20` bidirectional (default), and `0x30` random. Checking Once Only after choosing forward changed that byte to `0x80`. The native speed presets changed only the 32-bit float at payload offset 8: slow `4.0`, medium `24.0` (default), and fast `80.0`. Native examples are `action_animation_{forward,backward,random,slow,fast,forward_once}_original.gsp`; all import and round-trip exactly.

The port's button dialog now offers those directions, Once Only when applicable, the three speed presets, and a custom numeric speed. A button click applies the chosen settings to its point's motion. Forward and backward wrap around a path; bidirectional motion reverses at an open path's endpoints; random motion samples a new path position. Once Only stops after a random move or a full trip back to the starting position. A second click stops a running button. This follows the [Sketchpad 5 Reference Center's Animation Button behavior](https://referencecenter.dynamicgeometry.com/gsp-reference-center/objects_btns_animateprops.htm). `tests/replay_animation_button_variants.txt` generated a forward/fast/Once Only button and a backward/slow button; Sketchpad 5 opened and saved the combined file byte-identically (2,432 bytes). It also accepted a port-generated custom speed of `12.5` byte-identically.

Native buttons for a circle point and a free point use direction code `0x00` at medium speed. The free-point dialog hides the direction menu; free points wander at random regardless of the stored code. The port creates those native defaults for each point type. `action_animation_circle_original.gsp` and `action_animation_free_original.gsp` import and round-trip exactly, and port-generated circle and free-point button files opened and saved byte-identically in Sketchpad 5.

The desktop Edit > Action Buttons > Animation flow was also exercised under Xvfb. Choosing Create added the fifth object, File > Save wrote a 2,240-byte sketch, and Sketchpad 5 opened and resaved that exact file byte-identically.

Multiple targets, indirect animation of higher constructions, parameters, and exact native timing remain open. The parser preserves the other settings bytes and treats unrecognized layouts as unsupported source content.
