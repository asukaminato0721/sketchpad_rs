# Animation Action Button

`tests/replay_animation_button_base.txt` creates a segment and a point at its midpoint. In Sketchpad 5, selecting the point and choosing Edit > Action Buttons > Animation opens a settings dialog. Accepting its defaults creates a code-62 button labeled `动画点` (Animate Point). The native file is `tests/fixtures/action_animation_original.gsp`.

The button group has seven records: `0x07d0` (28-byte header), `0x07d2` (one target, point 4), `0x07d3` (36-byte animation settings), `0x0906` (24-byte action payload), `0x07d5` (label), `0x07d8` (auxiliary), and `0x07d7` (terminator). The action payload has nested code `0x0906`, length 24, code 12 at offset 8, value 2 at offset 12, and the button's screen anchor at offsets 20–23. `assets/action_animation_group.bin` preserves the native 188-byte group. The settings payload remains opaque so its unrecognized fields survive file edits.

Clicking the native button moved the constrained point from parameter 0.5 to 0.60276 in the saved sample while leaving the button group unchanged. The clicked file is `tests/fixtures/action_animation_clicked.gsp`. The native button did not show a floating Motion Controller in the click capture.

The port decodes this default group as an editable Animation Button. Edit > Action Buttons > Animation creates one for a free point or a point on a segment, circle, or arc. A click starts that point in the existing motion engine without opening the controller. The native and clicked files import with `partial_view=false` and reencode byte-identically. `tests/replay_animation_button.txt` creates an English `Animate Point` button. Sketchpad 5 opened and saved that port-generated file byte-identically (2,240 bytes, 91 records). Clicking it moved the point; the resulting native save is `tests/fixtures/action_animation_port_clicked_by_wine.gsp` and reencodes byte-identically in the port. Desktop captures at `/tmp/sketchpad_animation_button_port_before.png` and `/tmp/sketchpad_animation_button_port_after_one.png` show the port button and the point's motion.

The editor currently uses its normal point animation speed and direction for a button. The native dialog's speed, direction, and path options have not been decoded or reproduced; only the observed default settings payload is treated as editable. Other settings stay preserved as unsupported source content.
