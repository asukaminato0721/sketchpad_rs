# Scalar-Parameter custom-tool given

Audited on 2026-09-30. This checkpoint covers the two declared
class-11/subtype-79 givens in
`Samples/个人专栏/汪志平作品/系列迭代案例.gsp`. It does not generalize the adjacent
subtype-80 or subtype-81 families.

## Native category evidence

The file registers `长方形系列图` and `平方差方格系列图`; each declares local object
1 as code 0, class 11, subtype 79, labeled `n`. Under Xvfb/Wine, holding the
Native Custom Tools control exposed both Chinese tool names. Selecting
`平方差方格系列图` displayed `1. 匹配参数 n` (match parameter `n`). Clicking the
visible `n=5` Parameter satisfied that input, and the following canvas click
materialized the magenta construction. Saving changed the file from 158,138 to
161,684 bytes and changed its SHA-256, establishing that invocation completed
rather than merely dismissing the prompt.

This is narrower than the independently proved class-11/subtype-33 generic
numeric category. The port therefore requires an actual scalar Parameter for
subtype 79; it does not accept an arbitrary scalar calculation or measurement.
The scratch captures are
`/tmp/subtype79_invoked_{selected,after_numeric,after_point,after_save}.png`.

## Stored placeholder boundary

Both groups have the exact record family
`07d0:28, 0907:94, 07d5, 07d8:2, 08a3:8, 07d7:0` already established for inert
numeric givens. Their mode is 3 and precision is 2. The supposed step/domain
regions contain cache-like bytes: interpreted as doubles, the first tool yields
approximately `2.918e265, 1.780e-307, 3.467e-308`, and the second yields
`1.195e269, 1.780e-307, 2.632e-308`. They are not valid ordinary Parameter
animation domains and are not input values.

The decoder consequently validates the strict zero-token placeholder layout and
uses the subtype only to assign `ToolInput(ScalarParameter)`. Its numeric unit is
Scalar so existing parameter calculations and the code-62 animation button can
type-check inside the isolated prototype. Binding requires a live scalar
`Kind::Parameter` on the active page. The desktop picker applies the same filter.

## Measured recovery and limits

Both isolated prototypes now decode instead of failing. They remain partial:
the 90-object first tool and 61-object second tool still contain unrelated
unsupported construction families. In the second tool, local object 53 now
decodes as the `逐显` Animation button targeting the scalar input with domain
1 through 5. Port-side invocation is intentionally still rejected at the
partial-prototype gate.

Across the full 1,599-file corpus, decoded prototype slots rise from 4,779 to
4,866 of 5,356 and unsupported prototype slots fall from 577 to 490. Drawing
coverage remains 1,599/1,599, all original round trips remain byte-exact, and
there are no decode failures. No standalone test case was added. The scan is
`/tmp/subtype79_coverage_all.log`.
