## Contextual boundary

Only a declared input with code zero/class 11/subtype 57 receives the abstract
`Function` category. Its group must contain exactly the six records above, a
parsable source-free function expression, valid label metadata, style zero, and
an eight-byte text-bound record. The stored placeholder expression remains
inert; the port does not invent a destination function from it.

The placeholder satisfies function source roles while its prototype is decoded.
Referenced expressions continue to distinguish every Function and Numeric role.
Generic Numeric placeholders are accepted only for Numeric roles before their
units are known. At invocation, a Function input must bind an actual supported
function on the active page. The editor selects it through the visible function
caption, not through an unrelated plotted curve or numeric caption.
