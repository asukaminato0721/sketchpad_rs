# Rectangular translation with one fixed and one marked distance

The two native probes use `dev/rectangular_mixed_wine_probe.sh` with the base sketch from `tests/transform_rectangular_distances_replay.txt`. Measurements 6 and 7 are marked in that order. In the native Translate dialog, the horizontal or vertical distance can then be switched from its marked value to a fixed centimeter value.

With a fixed horizontal value of 2 cm and marked vertical measurement 7, the translated point is object code 18. Its `0x07d2` references source point 5 and vertical measurement 7. With marked horizontal measurement 6 and a fixed vertical value of 2 cm, the point is code 19 with references `[5, 6]`. Both use the transformed-point header marker `51 5c`. The two 28-byte `0x07d3` payloads differ only in their code byte: the fixed offset in pixels is at offset 4, the fixed centimeter value at offset 12, a 32-bit value `1` at offset 20, and zero bytes at 24–27. Native files are saved as `tests/fixtures/rectangular_mixed_horizontal_original.gsp` and `tests/fixtures/rectangular_mixed_vertical_original.gsp`; both import without partial view and round-trip byte-identically without edits.

The port evaluates the marked axis from its live measurement and the fixed axis from the signed centimeter value. `tests/transform_rectangular_mixed_replay.txt` creates both modes in one sketch, moves a defining point for each measurement, and saves. Sketchpad 5 opened the generated sketch after the moves and saved it byte-identically. Core and editor tests verify the reference mapping and live positions.
