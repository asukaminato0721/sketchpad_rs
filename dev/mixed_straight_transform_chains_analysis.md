# Mixed fixed and numeric Ray/Line transform chains

The supported source set for fixed rotation (27), fixed dilation (30), numeric-angle rotation (29), and numeric-ratio dilation (33) is primitive `Ray`/`Line` plus their fixed and numeric rotation/dilation images. Every target retains the source extent: native class 2, subtype 13 for a ray or 12 for an infinite line. These kinds remain excluded from the finite-segment predicate. Graph axes, bisectors, parallel and perpendicular lines remain outside this source guard; plotted-point host support is independent.

Eight native UI controls, retained as `tests/fixtures/mixed_straight_chain_{fixed_rotation,fixed_dilation,numeric_angle,numeric_ratio}_{ray,line}_original.gsp`, independently create all four transformations of each transformed source. Each control has source 8, center 1, and targets 12–15. The fixed targets reference `[8,1]`; numeric-angle target 14 references `[8,1,10]`; numeric-ratio target 15 references `[8,1,11]`. The fixed rotation has its existing 36-byte constraint; fixed dilation has its existing 12-byte constraint; numeric targets have no constraint. No new group layout is inferred. All targets inherit the source's magenta, thick, dashed stroke.

Source numeric inputs depend on parameter `n`; target numeric inputs depend independently on `j`. A source's zero ratio or undefined calculation suppresses descendant geometry even when the target's own input is finite. Negative ratios reverse direction about the center without changing Ray/Line mode. Restoring the source input restores every descendant. Saving a known suppressed transform graph is supported; authoring a transform of an initially undefined source remains rejected.

The regression `mixed_straight_writer_chains_follow_live_inputs_and_recover` constructs a 51-object graph covering all 32 transformed-source combinations. Its native-verified writer fixtures cover the initial graph, center/source/input edits, negative inputs, source zero and undefined inputs, target zero inputs, fixed zero ancestors, and copied dependencies after deleting the original source parameter. Copying translates free geometry by 20 pixels and remaps numeric dependencies independently. The four copied descendants survive deletion of the original parameter.

The drawing-scoped corpus audit found no fixed-on-numeric or numeric-on-fixed ray/line groups. A numeric-on-numeric Line in `../gsp-rs/tests/Samples/热研系列/滚动系列/正n边形的滚动.gsp` has object 28 referencing `[27,26,13]`. Its parent 27 references `[3,26,15]`, where object 3 is code 58 `GraphAxis`, not a primitive Line. This implementation did not reinterpret that axis as a primitive line. The later, independently verified axis-rotation pass now admits this exact fixed/numeric rotation role without broadening other axis transforms; see `axis_rotation_analysis.md`.
