# Simultaneous midpoint iteration with point bindings

The sibling fixture
`../gsp-rs/tests/fixtures/gsp/static/简单迭代/三角形.gsp` contains three free
vertices, three sides, and three midpoints. Its paired `三角形.htm` lists those
nine base constructions; JavaSketchpad export omits the iteration. A disposable
copy opened in native Sketchpad 5, showed nested medial triangles and red point
images, and saved byte-identically. That source is retained as
`tests/fixtures/mapped_midpoint_triangle_native_verified.gsp`.

Definition object 10 has code 76, class 14, subtype 64. References are
`[1,2,3, 8,9,7, 4,5,6,7,8,9]`: three simultaneous seeds, one three-point image
branch, then carried constructions. Its 24-byte `090a` payload is
`000000000000030001000000550450230300000000000000`, including fixed depth 3.
Objects 11–16 are code 77, class 15, subtype 65, with references `[4,10]`
through `[9,10]`. The first three carry sides; the last three carry midpoint
images. Point bindings retain shape byte 11 and RGB bytes 12–14. The remaining
header fields are preserved when editing those styles.

All seed substitutions occur together before evaluating the next branch.
For the original coordinates the first carried side is
`(751,467.5)–(853,319.5)`; the first additional image of midpoint 7 is
`(802,393.5)`. The base midpoints are already visible, so midpoint bindings add
generations 2 through 4 at depth 3. Side bindings add generations 1 through 3.
The implementation permits midpoint dependencies alongside the previously
verified free-point/vector/segment graph and shares the existing state
deduplication and resource bounds across point and segment evaluation.

Native carried references include prerequisites that need no visible binding:
the ant fixture carries many points but binds only segments. Consequently the
existing `add_mapped_point_iteration` keeps its segment-binding behavior.
`add_mapped_point_iteration_with_bindings` adds an explicit visible subset;
the replay command accepts optional binding IDs after the depth. Selecting and
copying a mapped iteration now includes its actual carried children. Point
bindings support color/point-style edits, SVG/canvas drawing, and picking.
Marker pixel sizes use the port's existing point-style approximation; exact
native iteration marker scaling is not established by this record evidence.

`tests/mapped_midpoint_iteration_replay.txt` constructs a depth-2 triangle with
six explicit bindings, then moves the first vertex in the native depth-3 source
and changes one point binding to Thick and RGB 14,150,210. Both output files
opened in native Sketchpad 5 with the expected nested triangles and colored
point images, and saved byte-identically. The two document regressions compare
their generated bytes directly to these saved fixtures. An editor regression
checks point-binding picking and hidden-object behavior.
