# Graph > Plot Value on Axis/Path

Sketchpad 5's [reference page](https://referencecenter.dynamicgeometry.com/gsp-reference-center/menus_graph_plotvalue.htm) describes plotting selected values on selected paths, or entering a value and path in a dialog. These probes cover the existing t₁ parameter, typed numeric values, and coordinate axes.

In `graph_plot_value_axis_original.gsp`, the original app plotted t₁ on the X axis. The new object is code 95. Its group contains only `0x07d0` (28-byte header), `0x07d2` (two references), and `0x07d7`. The references are parameter 1 and X axis 5; no coordinate value is stored. The observed group is `assets/graph_plot_value_axis_group.bin`. The plotted point appears at one axis unit from the origin and follows origin drags. It has the original medium red point style.

`plot_axis_records::decode_group` recognizes that record layout. `Document::position` evaluates the point from the parameter and axis origin/unit points. The native renderer and SVG exporter render it through the normal point path. The Graph menu uses the selected parameter and, when selected, a coordinate axis. Without an axis selection it uses the active X axis. `gsp_probe replay` accepts `plot_axis SOURCE [AXIS]`.

`tests/graph_plot_value_axis_replay.txt` generates three variants: a parameter plus X axis, the original's parameter/table/frame arrangement plus X axis, and a parameter plus Y axis. Each generated file opened in Sketchpad 5 under Wine and saved byte-identically. Rust tests check original byte preservation, frame movement with undo/redo and save/reopen, generated file bytes, and Y-axis placement.

Typing `2.5` in the original app's Plot Value dialog produced `graph_plot_value_literal_original.gsp`. The new point is code 123 with `0x07d0`, `0x07d2`, `0x07d3`, and `0x07d7` records. The `0x07d2` record references X axis 3, and `0x07d3` stores tag 123 followed by an `f64` value of 2.5. The group template is `assets/graph_plot_value_literal_group.bin`. The point appears 2.5 units from the origin; no separate parameter object is created.

The port decodes and writes fixed numeric axis points. The native Graph menu opens a value dialog when no parameter is selected, and the replay command is `plot_axis_value VALUE [AXIS]`. `tests/graph_plot_value_literal_replay.txt` generates positive X and negative Y examples. Both opened with the expected positions in Sketchpad 5 and saved byte-identically. Rust tests check original bytes, frame movement with undo/redo, stored value edits, and generated files.

Selecting segment AB and typing `0.4` produced `graph_plot_segment_literal_original.gsp`. Its code 123 group has the same record layout as the axis case, with the segment ID in `0x07d2`; the point is 40% of the way from A to B. Selecting t₁ and then choosing AB in the dialog produced `graph_plot_segment_parameter_original.gsp`, whose code 95 group similarly references the parameter and segment. The latter file's t₁ display box grew when the original app recalculated its font bounds. `ParameterGroup::parse` now accepts a positive, bounded box consistent with the stored anchor while retaining the exact source bytes.

`Document::position` interpolates both segment and axis paths, so plotted points follow endpoint movement. The Graph menu changes its label to Plot Value on Path when a path is selected, and headless replay accepts `plot_path` and `plot_path_value`. `tests/graph_plot_segment_replay.txt` produces minimal fixed and live segment examples with no coordinate system. Both opened with the expected points in Sketchpad 5 and saved byte-identically. Rust tests verify original byte preservation, endpoint movement, and exact generated files.

The same code 123 layout also appears when the original app plots values on a circle, line, or ray. Original fixtures `graph_plot_circle_literal_original.gsp`, `graph_plot_line_literal_original.gsp`, and `graph_plot_ray_literal_original.gsp` use values 0.25, -0.5, and 2 respectively. The circle point is at the top, so its value is measured in counterclockwise turns from the rightmost point. Line and ray values extrapolate from the first point through the second; rays require values of at least zero, while lines accept negative values. `tests/graph_plot_more_paths_replay.txt` generates these three literal forms and a parameter driven circle point. Each generated file opened and saved byte-identically in Sketchpad 5. Rust tests check the original bytes, path movement, domain validation, and exact generated files.

The writer supports the parsed t₁ parameter, finite numeric literals, graph axes, and segments. Expressions, other numeric sources, and further paths remain to be probed.
