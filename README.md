# Sketchpad RS

Experimental Linux editor for Sketchpad 5 `.gsp` documents. It uses winit and egui for the window and controls, and wgpu with a WGSL shader for sketch geometry.

## Run

```sh
cargo run --bin sketchpad_rs -- path/to/sketch.gsp
```

The path is optional. Use the File menu to create, open, save, close, and quit. New, Open, Close, and Quit prompt about unsaved changes. The File menu can export the visible page as SVG or PDF and send it to the Linux default printer. PDF output requires `rsvg-convert`; printing also requires `lp`. The toolbar creates points, segments, and circles. Clicking a segment, circle, or arc with the Point tool creates a point constrained to that object. Select the required objects for the Construct commands. The Measure menu adds live Length values for segments, Distance values for two points, and Circumference and Radius values for circles. Edit > Cut, Copy, and Paste use an internal sketch clipboard for supported objects; Edit > Clear or Delete removes selected objects and their dependents in supported single-page files. The Transform menu can translate or rotate a point, reflect a point or circle across a selected line, or dilate a point or circle around a selected center. Drag a point to update its dependents or its position on a segment, circle, or arc. Scroll over the canvas to zoom. Multi-page files have page controls in the left panel.

For a small interoperability sample, run `cargo run --bin gsp_probe -- demo /tmp/sketch.gsp`.

## Current scope

The writer supports free points, points on segments, circles, and arcs, polar translated, reflected, scaled, and rotated points, reflected and scaled circles, segments, circles by center and point or radius segment, midpoints, lines, rays, parallel and perpendicular lines, angle bisectors, arcs through three points or on circles, intersections of straight objects, lines with circles, and two circles, and segment length, point distance, circle circumference, and circle radius measurements. It can update coordinates, supported point constraints, and visibility in place in existing documents, and remove selected objects with their dependents in supported single-page documents. Copy includes a selected object's construction parents; Paste duplicates them with a 20-unit offset. It preserves unsupported source records byte for byte. Structural edits to a document with unsupported content are refused when saving. Saves write through a temporary file in the destination directory and rename it into place.

Other Sketchpad features are incomplete. In particular, most transformations, other measurements, graphing, text, images, tables, custom tools, actions, importing, page setup, print preview, and full multi-page editing are still pending. See [COMMAND_PARITY.md](COMMAND_PARITY.md) for the command inventory. This build is not ready as a Sketchpad 5 replacement.

## Verification

Run `cargo test`. Tests cover record parsing and byte preservation on bundled fixtures, dependency updates, geometric clipping, undo/redo, visibility encoding, and save/reopen. A nine-object file generated by the Rust writer was opened, edited, and saved in the supplied Windows Sketchpad 5 through Wine; the port reopens the resulting file. A generated 13-object file with four circle intersections also opened and rendered in Sketchpad 5. A native window smoke test ran for eight seconds on the Linux desktop without a panic. Full command and interaction verification remains open.

`gsp_probe` provides headless `inspect`, `diff`, `verify`, `demo`, `replay`, and `svg` commands for comparing original and generated files and exercising document commands. The Ghidra scripts and current binary analysis are in [dev/ANALYSIS.md](dev/ANALYSIS.md).
