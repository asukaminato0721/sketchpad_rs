# Sketchpad RS

Experimental Linux editor for Sketchpad 5 `.gsp` documents. It uses winit and egui for the window and controls, and wgpu with a WGSL shader for sketch geometry.

## Run

```sh
cargo run --bin sketchpad_rs -- path/to/sketch.gsp
```

The path is optional. Use the File menu to create, open, save, close, and quit. New, Open, Close, and Quit prompt about unsaved changes. The toolbar creates points, segments, and circles. Select the required objects for the Construct commands. Drag a free point to update its dependents. Scroll over the canvas to zoom. Multi-page files have page controls in the left panel.

For a small interoperability sample, run `cargo run --bin gsp_probe -- demo /tmp/sketch.gsp`.

## Current scope

The writer supports free points, segments, circles by center and point, midpoints, lines, rays, parallel and perpendicular lines, and intersections of straight objects, lines with circles, and two circles. It can also update coordinates and visibility in place in existing documents. It preserves unsupported source records byte for byte. Structural edits to a document with unsupported content are refused when saving. Saves write through a temporary file in the destination directory and rename it into place.

Other Sketchpad features are incomplete. In particular, complex object rendering, transformations, measurements, graphing, text, images, tables, custom tools, actions, import/export, printing, and full multi-page editing are still pending. See [COMMAND_PARITY.md](COMMAND_PARITY.md) for the command inventory. This build is not ready as a Sketchpad 5 replacement.

## Verification

Run `cargo test`. Tests cover record parsing and byte preservation on bundled fixtures, dependency updates, geometric clipping, undo/redo, visibility encoding, and save/reopen. A nine-object file generated by the Rust writer was opened, edited, and saved in the supplied Windows Sketchpad 5 through Wine; the port reopens the resulting file. A generated 13-object file with four circle intersections also opened and rendered in Sketchpad 5. A native window smoke test ran for eight seconds on the Linux desktop without a panic. Full command and interaction verification remains open.

`gsp_probe` provides headless `inspect`, `diff`, `verify`, `demo`, and `replay` commands for comparing original and generated files and exercising document commands. The Ghidra scripts and current binary analysis are in [dev/ANALYSIS.md](dev/ANALYSIS.md).
