# Sketchpad RS

Experimental Linux editor for Sketchpad 5 `.gsp` documents. It uses winit and egui for the window and controls, and wgpu with a WGSL shader for sketch geometry.

## Run


```sh
cargo run -- path/to/sketch.gsp
```

The path is optional. Use the File menu to create, open, and save a document. The toolbar creates points, segments, and circles. Select two points for the Construct commands. Drag a free point to update its dependents. Scroll over the canvas to zoom. Multi-page files have page controls in the left panel.

For a small interoperability sample, run `cargo run -- --make-demo /tmp/sketch.gsp`.

## Current scope

The writer supports free points, segments, circles by center and point, midpoints, lines, rays, and parallel and perpendicular lines. It can also update coordinates and visibility in place in existing documents. It preserves unsupported source records byte for byte. Structural edits to a document with unsupported content are refused when saving. Save As writes through a temporary file in the destination directory and renames it into place.

Other Sketchpad features are incomplete. In particular, complex object rendering, transformations, measurements, graphing, text, images, tables, custom tools, actions, import/export, printing, and full multi-page editing are still pending. See [COMMAND_PARITY.md](COMMAND_PARITY.md) for the command inventory. This build is not ready as a Sketchpad 5 replacement.

## Verification

Run `cargo test`. Tests cover record parsing and byte preservation on bundled fixtures, dependency updates, geometric clipping, undo/redo, visibility encoding, and save/reopen. A nine-object file generated by the Rust writer was opened in the supplied Windows Sketchpad 5 through Wine and rendered there. A native window smoke test ran for eight seconds on the Linux desktop without a panic. Full command and interaction verification remains open.
